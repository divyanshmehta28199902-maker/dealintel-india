Primary Goal

Currently the Overview and Analytics tabs display very similar information.

Separate their responsibilities so each tab has a unique purpose.

⸻

1. Redesign the Purpose of Overview

Overview should answer:

“What is happening in my pipeline today?”

Keep this page simple and operational.

Display:

* Active Deals
* Total Pipeline Value
* Average Deal Size
* Deals Requiring Attention
* Deals Closing Soon
* Recent Activity
* Today’s Tasks
* Recent Messages
* Recent Notes
* Quick Actions

This page should function as a dashboard, not an analytics page.

Versioning

The project uses the following version format:

Major.Minor.Patch
Example
1.0.0
1.1.0
1.2.5
2.0.0

⸻

Version Meaning

Major

Breaking changes

Examples:

* Complete platform redesign
* Database architecture changes
* API changes

⸻

Minor

New features

Examples:

* New dashboard
* New valuation model
* New AI feature

⸻

Patch

Bug fixes

Examples:

* Performance improvements
* UI fixes
* Security updates
* Documentation updates

⸻

Release Types

Type	Description

Beta	Public testing
Stable	Production-ready
Patch	Bug fixes
Hotfix	Critical production fix
